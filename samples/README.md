# Samples

`visit-01.wav` is a **synthetic** 2.5 minute primary-care follow-up: a fictional
patient ("Mr. Alvarez") on lisinopril and metformin, with a new dry cough. Two
text-to-speech voices read the script in `visit-01.script.txt`. No real person,
no real patient, no protected health information. Use it freely to test every
lesson without recording anything yourself.

Regenerate it (or write your own role-play) with the recipe in
`docs/08-evaluate.md`.
